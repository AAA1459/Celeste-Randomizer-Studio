# Celeste-Randomizer-Studio
A route-visualization tool help in writing the configuration files for Celeste Randomizer Helper

About Celeste randomizer and configuration files: https://github.com/rhelmot/CelesteRandomizer/blob/master/docs/metadata.md

this tool can：
- list the route conditions and compare them with the player's abilities.
- Automatically selects entire room text in file when select all in the room edit box, then you can replace them.
- uhh discover more as you use it.
